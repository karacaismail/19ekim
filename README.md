# iStoc saha ve pazarlama planı

iStoc için 19 Ekim 2026 tarihli tahta kararlarının alt kırılımları: tepede İsmail Karaca, altında dört rol ağacı
(dijital pazarlama, masa başı pazarlama, saha satış, organizatör) ve kurmay olarak asistan. Her rol için saat saat bir gün,
haftanın ritmi, hedefler, iş akışı, 90 günlük plan ve personel onboarding’i; ortak sayfalarda hedef grafikleri,
istihdam takvimi, eylem planı, iş akışları, çok katmanlı pazarlama ağı ve çalışma düzeni.

Yayın: <https://karacaismail.github.io/19ekim/>

## Geliştirme

```sh
npm ci
npm run dev       # http://localhost:4321/19ekim/
npm run verify    # kontrol + derleme + tarayıcı testleri
```

Yığın: Astro 7, React 19, Mantine 9, ECharts 6. Ayrıntılar ve tasarım kuralları için [AGENTS.md](AGENTS.md).
